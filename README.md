# DikForever

와우 포에버(WoW: Forever)용 개인 애드온 **DikForever** 배포 저장소입니다.

> 이 저장소는 **자동 생성**됩니다. 직접 수정하지 마세요. 수정해도 다음 배포 때 덮어써집니다.

## 설치·업데이트 방법

업데이터 프로그램(`DikForeverUpdater.exe`)은 이 저장소에 들어 있지 않습니다. 배포자에게 따로 받으세요.

1. `DikForeverUpdater.exe` 를 실행합니다.
2. `찾아보기…` 로 와우 포에버 설치 폴더(예: `_classic_beta_`)를 고릅니다.
   `World of Warcraft` 폴더나 `Interface\AddOns` 폴더를 골라도 됩니다.
3. `모두 복사(권장)` 를 그대로 두고 `확인` 을 누릅니다.
4. 게임이 켜져 있다면 게임 안에서 `/reload` 를 입력합니다.

기존 파일은 자동으로 백업되며, 최신 3개만 보관됩니다.

### 처음 실행할 때 파란 경고 창이 뜨면

서명되지 않은 프로그램이라 Windows SmartScreen 경고가 나올 수 있습니다.
**추가 정보 → 실행** 을 누르면 됩니다.

## 설정 프리셋 붙여넣기

배포자가 설정 프리셋을 함께 올린 경우, 업데이터가 설정 문자열을 클립보드에 복사해 줍니다.

1. 게임에서 `/dikf 이전` 을 입력합니다.
2. 가져오기 칸에 `Ctrl+V` 로 붙여넣고 가져옵니다.
